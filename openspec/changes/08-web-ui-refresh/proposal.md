# Web UI refresh

## Why

Refresh the activities experience and establish reusable Tailwind CSS v4 and DaisyUI components for subsequent page restyling.

## What Changes

- Add Tailwind CSS v4 with DaisyUI and a light, accessible theme.
- Restyle shared components and the application shell.
- Replace activity quick-add with a shared create/edit native dialog and improve the activity filters and list.
- Document the shared styling and dialog/filter patterns.

## Capabilities

### Modified Capabilities
- `web-client`: activity management and shared responsive visual behavior.

## Impact

- `apps/web` and `docs/web-design.md`.
